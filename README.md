# OSCURITÀ

Gioco horror 3D in prima persona, interamente in un unico file HTML (Three.js r128 da CDN, nessuna build).

## Fasi
1. **Il Manicomio** – 5 pagine, 1 mostro
2. **Le Cantine** – 7 sigilli, 1 mostro
3. **Il Bosco dei Sussurri** – 9 bambole, 2 mostri
4. **La Cappella** – 12 candele, 2 mostri più veloci

Labirinti generati casualmente a ogni partita. Gioca con le cuffie e al buio.

## Controlli
| Azione | Desktop | Mobile (orizzontale) |
|---|---|---|
| Muoversi | WASD / frecce | stick a sinistra |
| Guardarsi attorno | mouse (clic per bloccarlo) | trascina a destra |
| Correre | Shift | pulsante CORRI |
| Torcia | F | pulsante TORCIA |
| Pausa | P / Esc | pulsante II |

## Come eseguirlo
Apri `index.html` in un browser moderno (serve connessione per caricare Three.js dal CDN).

Online con GitHub Pages: il workflow `.github/workflows/pages.yml` pubblica il gioco a ogni push su `main`.
Basta attivare *Settings → Pages → Source: GitHub Actions*.
